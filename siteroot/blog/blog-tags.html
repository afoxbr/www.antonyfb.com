Blog Tags!

I have realised that I didn’t put up a post letting my dear hypothetical readers know about a shiny new feature I bodged into existence for this site last month. Please forgive me.

I’ve added tags to the blog index page. This means if you want to just see my posts about books/reading, click that tag and everything else will disappear. It’s JavaScript dependent, so I’m afraid it won’t work absolutely everywhere, but it’s a small QoL feature so I can live with that. I’m thinking about having the buttons (including the also JS-dependent theme button at the top of the page) generated by the script so they won’t even appear for people with noscript plugins or simple browsers like Dillo. I suspect that’ll be a bit nicer than just having nonfunctional buttons hanging around. I’ll likely get around to it eventually.

I wonder if he'd have liked JS.

It’s not impossible that I start doing separate RSS feeds divided by topic in the same way the tags are, but I’m not sure if it’s worth the effort. Honestly I have no idea if anyone even subscribes to my RSS feed as is. If anyone reads this and would like me to divide the feed into topics (while keeping the current all posts feed), please do email me and let me know your thoughts.

Alright, that’s all from me.

Toodles,
